## 1. What This Is

The database covers four areas of automotive terminology, each with names in 4 languages:

| Section | Content | Count |
|---------|---------|-------|
| **Vehicle classes** `vehicle_classes` | CN/EU/JP/US classification systems + body styles + powertrain types | 6 subsystems |
| **Glossary** `glossary` | 10 categories: powertrain, transmission, chassis, braking, safety, driver assist, new energy, body, lighting/comfort, tire/wheel | 72 terms |
| **Brands** `brands` | 164 mainstream brands grouped by country | 164 entries |
| **Models** `models` | Current, order-suspended, discontinued, and concept models (split per brand, with production years & status) | 3032 entries |
| **Cross-market aliases** `cross_market` | Same car under different names in different markets | 24 groups |

Goals:

- **Human-readable**: `dist/vehicle-names-database.md` — table-based, ready to read or share.
- **AI-callable**: `dist/vehicle-names-database.json` — fixed schema, directly usable by programs/AI tools.
- **Community-friendly**: `data/` is split per brand so many people can edit in parallel with minimal merge conflicts.

## 3. Language Keys and Field Conventions

Four language keys (lowercase):

| Key | Language | Notes |
|-----|----------|-------|
| `en` | English | Official brand/model names, international terms |
| `zh-CN` | Simplified Chinese | Mainland China usage |
| `zh-TW` | Traditional Chinese | Taiwan usage (HK/Macau noted when relevant) |
| `ja` | Japanese | Japanese-market rendering (katakana or kanji) |

Common fields:

| Field | Meaning |
|-------|---------|
| `id` | Globally unique, e.g. `glossary:powertrain:01`, `brand:jp:toyota`, `model:toyota:corolla` |
| `name` / `names` | The name, localized under `names` |
| `abbr` | Abbreviation (glossary only, e.g. `TPMS`) |
| `note` | Notes: meaning, source, aliases, history |
| `verified` | `verified` (confirmed) / `pending` (needs review) |
| `country` | Brand's home country (brands only) |
| `segment` / `body_style` / `powertrain` | References into `vehicle_classes` ids |
| `status` | New-car sales state: `current` (new orders accepted in at least one covered market) / `order-suspended` (manufacturer paused new orders without confirming permanent discontinuation) / `discontinued` / `concept` |
| `years` | Production years, e.g. `1966–present` |

## 4. Naming Rules

- Brand id: `brand:{country_code}:{lowercase_english_name}` (e.g. `brand:jp:toyota`).
- Model id: `model:{brand}:{lowercase_model_name}` (e.g. `model:toyota:corolla`).
- Term id: `glossary:{category}:{two-digit}` (e.g. `glossary:safety:01`).
- Class id: `class:{system}:{code}` (e.g. `class:cn:a`, `class:jp:kei`).

## 5. Model Data Files

Files under `data/models/` are split per brand/group:

- Filename suggestion: `{region}_{brand}.json`, e.g. `jp_toyota.json`, `de_vw_group.json`, `cn_byd.json`.
- Top-level shape: `{"models": [...]}`.
- Each model entry needs: `id`, `brand`, `names{en,zh-CN,zh-TW,ja}`, `segment`, `body_style`, `powertrain`, `status`, `years`, `note`.
- Judge status within the record's market scope and by new-car sales/order acceptance; used-car availability does not mean new cars are still on sale. If the manufacturer explicitly pauses new orders without confirming permanent discontinuation, use `status: "order-suspended"` and record the date and reason in `note`. Use `discontinued` only when sales/production have ended for the covered record. Separate a revived name or a different market generation when needed.
- When a name is uncertain, set `verified: "pending"` and add an entry to `pending_verification.json`.

Example entry:

```json
{
  "id": "model:toyota:corolla",
  "brand": "Toyota",
  "names": {"en": "Corolla", "zh-CN": "卡罗拉/雷凌(广汽)", "zh-TW": "Corolla Altis", "ja": "カローラ"},
  "segment": "class:cn:a",
  "body_style": "body:sedan",
  "powertrain": "pt:ice",
  "status": "current",
  "years": "1966–present",
  "note": "Best-selling car nameplate worldwide; Levin is the FAW sibling name in China",
  "verified": "verified"
}
```

## 7. Known Pitfalls (for AI content generation)

- Toyota: "荣放/威兰达" are the China names for RAV4 siblings; Taiwan uses `RAV4`. "威驰" is China-only; Taiwan uses `Vios`.
- Honda: "飞度" in China, `Jazz` in Europe/HK/Macau; `Civic` is nicknamed "喜美" in Taiwan.
- Mazda: Japan formerly used `デミオ/アクセラ/アテンザ/ロードスター`; since 2019 unified to `MAZDA2/3/6` and `Roadster`.
- Brand name variants across regions (Mercedes 賓士/平治, VW 福斯/福士, Volvo 富豪, Infiniti 無限, Subaru 速霸陸, Lexus 凌志) must be respected in Traditional Chinese content.
- Japanese kei cars have strict size/displacement limits (`vehicle_classes.jp_categories`) — do not confuse with "microcars".
- Model data distinguishes `current`, `order-suspended`, and `discontinued`; verify market scope and production years before citing historical models.

## 8. Sources & Disclaimer

- **Standards**: GB/T 3730.1-2001/2022, GB/T 19596 (new energy), Japanese Road Transport Vehicle Act (kei-car rules revised 1998), US 40 CFR 600.315-08 (EPA), EU segment definitions (A–F).
- **Institutions**: Japanese MLIT, EPA/NHTSA/IIHS, Euro NCAP, JAMA, C-NCAP.
- **References**: Wikipedia (EN/JA), cross-strait translation comparison articles, official brand websites and Taiwan distributors (Hotai, Yulon, CMC, etc.).
- **Limitations**: Class size values are industry practice, not mandatory standards; some entries await verification (`pending_verification`). Data is for study/translation/reference only — always cross-check official sources for formal publications.
